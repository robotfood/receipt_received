# Design Principles

## Product Shape

This is a local bookkeeping workbench, not a marketing site. The interface should feel quiet, precise, and operational.

## Principles

1. Show the source image before asking the user to trust extraction.
2. Keep actions explicit: open, process, review, export.
3. Treat model output as provisional until reviewed.
4. Prefer dense, scannable layouts over decorative panels.
5. Use thumbnails and filenames to make document identity obvious.
6. Use one primary action per screen.
7. Keep long-running work visible with a blocking status and spinner.
8. Make warnings concrete and tied to validation failures or model pass failures.
9. Preserve the original image as the stable reference throughout review.
10. Avoid hiding processing state behind redirects or silent waits.
